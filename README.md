# PRODIGY_ML_05: Food Recognition & Calorie Estimation

This repository implements a machine learning model to estimate calorie content from visual food item feature representations.

## Dataset
- Food-101 Dataset / Extracted Visual Feature Embeddings

## Pipeline Overview
1. **Feature Extraction**: Extracted high-dimensional visual descriptors representing food items.
2. **Model Training**: Trained a **Random Forest Regressor** to predict continuous calorie values based on image attributes.
3. **Evaluation**: Evaluated estimation accuracy using RMSE and R² Score.
